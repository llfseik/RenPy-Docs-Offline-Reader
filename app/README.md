# Ren'Py 中文文档 · 离线桌面版

把 [doc.renpy.cn](https://doc.renpy.cn/zh-CN/) 的中文参考文档（Ren'Py **8.5.4**）抓取到本地，
配一套不依赖网络、不依赖后端的全文搜索，并打包成独立的桌面程序。

## 快速开始

双击 `Ren'Py 中文文档.lnk`（或 `RenPyDocs.exe`）即可。没有命令行、没有地址栏，也不用起服务器。

- 窗口里就是完整的文档站：左侧目录、右侧正文、搜索、锚点跳转
- 窗口最顶部是**标签栏**：从搜索结果点开的每个词条都会新开一个标签，可关闭、可切换，像浏览器一样（见下文“标签页”）
- 自动记住窗口位置、大小和最大化状态，下次打开回到原处（多显示器不会乱跑）；首次运行在主屏居中
- 启动后自动比对线上版本，发现更新会弹窗；点“确定”就在应用内重新抓取并重建索引
  （隐藏浏览器抓取 + 内嵌 Python 重建，约 3~5 分钟），旧版本保留为 `site.bak`，失败则不动本地
- 外部链接（github.com、renpy.org 等）交给系统默认浏览器打开
- 依赖系统自带的 Microsoft Edge WebView2 运行时（Win10/11 通常已预装）
- 整个 `app` 文件夹是自包含的，可以复制到桌面或 U 盘

## 搜索

| 入口 | 说明 |
| --- | --- |
| 侧边栏的“搜索文档”输入框 | 回车进入搜索页，结果出现在右侧内容区 |
| 搜索页上的同一个输入框 | 边输入边出结果，不刷新页面 |
| 右下角的放大镜悬浮按钮 | 一键进入搜索页 |
| 任意页面按 `/` | 聚焦搜索框 |

- 多个关键词用空格分隔，按“同时包含”匹配，例如 `renpy.show 图像`
- 结果按内容形态分层，与原版文档一致：**API 定义 → 代码块 → 章节标题 → 正文描述**
- 代码块结果摘出命中行（上下各带一行上下文）并高亮，点击直接跳到该代码块
- 搜索框下方有最近 5 条搜索记录，点击可快速复用，右侧 `×` 删除
- 关键词同步到地址栏（`?q=`）

## 标签页

窗口最顶部一条标签栏，行为跟浏览器一致。它是窗口自己的一部分（WinForms 原生控件），**不占用页面里的任何位置**，
所以文档页面的布局、左侧目录、顶部导航按钮都保持原样。

| 操作 | 效果 |
| --- | --- |
| 点搜索结果 | 新开一个标签，标签名就是那个词条（如 `config.save_directory`、`scene语句`），并直接跳到该词条的位置 |
| 点文档里的普通链接 | 在当前标签里跳转，标签名跟着换成新页面标题 |
| 点标签 | 切到那个标签，**回到上次读到的地方**（各自的滚动位置会记住） |
| 标签上的 `×` / 鼠标中键 | 关闭该标签；关掉当前标签后自动激活右边的，最后一个关掉会回到首页 |
| `+` | 新开一个首页标签 |
| `Ctrl+T` / `Ctrl+W` | 新建 / 关闭标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Ctrl+1`…`Ctrl+8`、`Ctrl+9` | 定位到第 N 个 / 最后一个标签 |

- **后退 / 前进和标签是联动的**：在标签里点了链接翻过页，后退就是退回上一页（标签不变）；如果这个标签是从搜索结果点开的、还没在它里面翻过页，后退会**把它关掉并回到搜索页那个标签**，所以不会越点越多；再按前进又能把它原样开回来
- 后退/前进按钮不可用时会自动变灰，判断依据也是这套标签历史

- 搜索页的标签名会带上关键词（`搜索：save`），所以同时开着几个搜索也分得清
- 标签和明暗主题都会保留到下次启动（最多 16 个标签，超出时丢弃最旧的）
- 同一个词条重复点开只会切到已有标签，不会开两份

## 收藏

文档里**每个词条右侧都有一颗五角星**（紧挨标题文字，在链接 `¶` 和地球图标之前，即 `★ ¶ 🌐`；鼠标移到标题上才显形）。点一下就变黄并加入收藏，
再点一下取消；收藏存在本机，关掉程序、更新文档都还在。

收藏是**大类 + 小类**的结构：

| 点哪里 | 收藏到什么 |
| --- | --- |
| 页面大标题（h1）上的星 | 只收藏这一篇文档（大类），不会顺手把里面的小类也收进来 |
| 某个标题 / 定义上的星 | 收藏这个词条（小类），同时这篇文档会作为大类一起出现在收藏里 |
| 大类已经亮着时再点大标题的星 | 取消整篇文档的收藏（连同下面的小类一起移出） |

右下角那一排按钮里，放大镜上面就是五角星入口：

- 进去是**收藏页**，版式和搜索结果一致：一行蓝色文档名（大类，后面带小类数量），下面用竖线缩进列出小类
- 只收藏了整篇文档时，文档名下面会带一段这篇文档的描述；一旦有词条加入，就只列词条
- 每个小类是 `章节路径 › 词条`，下面再跟两行灰色的原文描述，方便直接认出是哪一条
- 点文档名或小类行会跳过去（桌面版新开一个标签）；行尾的黄星单独移出那一条，文档名右侧的黄星移出整篇
- 顶部有它自己的筛选框（和侧栏搜索互不相干），能按文档名、章节路径、词条名和描述片段筛
- **排序跟收藏先后无关**：大类按左侧目录的文档顺序，小类按它在这篇文档里的先后

## 界面上的附加功能

- 内容区顶部（与标题、“文档捉虫”同一行）：`←` 后退、`🏠` 首页、`→` 前进；不可用时自动变灰
- 窗口最顶部：标签栏（新建、关闭、切换、记住滚动位置）
- 标题右侧一排图标（悬停标题时一起出现）：五角星（收藏）、`¶`（永久链接）、地球（复制线上链接并在浏览器打开）；函数/类的定义框再多一个复制按钮
- 复制按钮只复制签名本身，例如 AlphaDissolve(control, delay=0.0, alpha=False, reverse=False)，不带 class 前缀、也不带下面的说明；点完会短暂变成对勾并提示「已复制签名」
- 点击文档中的图片：页内灯箱放大，`Esc` / 点击空白处关闭
- 右下角：检查更新、切换文档、收藏、搜索、明暗主题、设置（齿轮）六个悬浮按钮；「切换文档」点开一个小列表，用来在六份文档之间切换（中文、繁中、英文、日文、Ren'Py Nightly Fix、Ren'Py Nightly Development；没下载的显示下载箭头，点一下现抓）。面板淡入淡出（0.17 秒），打开时每一行依次浮现。标题右边有一个**选择 / 删除**两档滑块（✓ / 垃圾桶图标）：删除档里每份**已下载**文档左侧的 ✓ 会变成红色垃圾桶，点一下会先弹确认框——确认后**真的删掉本地文件**（`site\<文档>`），但收藏、标签页、搜索记录都保留；这一行不会消失，而是变成灰色 + 下载箭头，想要时再点一下重新下载。**正在读的那份也能删**：删完直接回到「请选择文档」页，重新下载回来再点它，之前的标签页会原样回来。删除档里**没下载那几行的下载箭头会淡出**（和 ✓ ↔ 垃圾桶同一个 0.2 秒渐变，拨回来再淡入），**正在下载的圆环照旧显示**、照样能点暂停 / 继续
- **六份文档的数据不互通**：点一下就直接切过去，不弹确认框；标签页、收藏、搜索记录都换成那份文档自己的（**明暗主题一起用**）。切回中文，之前的标签页和收藏原样回来
- 「检查更新」版本号和构建时间一起比，任一新就提示：中文的版本取站点首页侧栏那句「8.5.4 说明文档首页」（站点那个 `documentation_options.js` 从 2024 年起就没更新过，只当兜底），时间取站点文件的 `Last-Modified`；英文去 `www.renpy.org` 读版本号，同样再比一次构建时间。检查时先弹一个小进度窗（标题「检查更新」），依次显示 连接文档站 → 读取线上版本 → 获取构建时间 → 读取版本文件 → 比较版本，进度条同步推进；连点只会有一个窗。弹窗里固定列「本地版本 / 本地构建 / 线上版本 / 线上构建」四项，已是最新时也照样列出来。比本地新就问你「更新」还是「取消」，确认后走同一套后台下载（进度窗、暂停都在）
- 查到「当前已是最新版本」时，弹窗里 `确定` 左边还有一个**「校验完整性」**：点一下就把当前文档逐个体检一遍——页面能不能打开、正文里引用的图片/样式/脚本在不在、图片是不是真的能解码（这一条专门抓「下载回来是一堆假图片」那种情况）。检查完要么告诉你「文件完整」（带文件数和图片数），要么告诉你坏了几处、分别是哪几类（图片损坏 / 文件缺失 / 页面异常 / 资源异常），并给一个**「重新下载」**按钮，点一下直接把这份文档重新抓一遍来修复
- **除了中文文档，其余五份默认都没有下载**：切换列表和「请选择文档」页上，没下载的文档右边有一个下载按钮（↓ 落盘图标），点一下会弹出和「检查更新」同款的进度窗（标题「正在下载文档」，带进度条和「取消下载」）。**中文文档也是同一套**（删掉之后重新下载走 doc.renpy.cn，抓的还是中文，不会变成英文）
  这一行会变成一个**慢慢填满的圆环**表示进度；鼠标移上去出现暂停符号，点一下就暂停，圆环变成继续符号，再点继续，进度窗里也会显示「已暂停」。进度只会往前走，不会往回退。
  下载在独立进程里跑，**关掉软件、切文档都不会中断**，下次打开会把进度接回来；下载完那一行自动变成可切换状态并显示版本号。万一文档站要求浏览器校验，会自动改用内嵌浏览器接着下载（这条只能在软件开着的时候跑）
- **没有可读的文档时**（删掉正在读的那份、删掉最后一份，或启动时发现文档已不在磁盘上）：会进到一张空白页，屏幕正中是「请选择文档」和文档列表，点一份就把它恢复并打开。这张空白页是**站点根目录的独立页面**（`site\picker.html`），所以删掉任何文档目录它都还在：顶部标签栏不显示、标签快捷键失效，右下角只保留明暗主题按钮
- 按钮列最上面的齿轮是**设置入口**：点一下弹出白色的设置窗（和「检查更新」「删除文档」同一套版式），里面五组：
  - **系统语言设置**：简体中文 / 繁體中文 / English / 日本語，切换软件界面语言（弹窗、按钮、提示、标签标题），界面字体也换成对应语言的本地字体（雅黑 / 正黑 / Segoe UI / Yu Gothic UI）；文档自己的标签保持文档原语言，搜索 / 收藏 / 请选择文档这些应用页面的标签会跟着切
  - **文档更新检查**：勾选「启动时检查文档更新」后，每次启动检查当前打开的文档有没有新版；和手动「检查更新」一样先显示检查进度窗，检查完弹「当前已是最新版本」，有新版就弹更新确认框。下面的「每天最多检查一次」**默认勾选**，同一天里只检查一次（日期记在 `%LOCALAPPDATA%\RenPyDocs\doc-check.txt`），手动检查不受影响
  - **关闭清除标签**：勾选「关闭后清除所有标签页」后，退出时删掉所有文档的标签记录，下次启动只打开上次那份文档的首页
  - **搜索记录数量**：横向滑块 0–10，控制每个文档最多保留几条搜索历史（0 = 不保留）；保存后当前页会刷新，并按新上限裁剪已经存下的记录
  - **软件更新检查**：网址输入框 + 勾选「启动时检查软件更新」（目前只保存，不联网）
  底部的**取消**丢掉这次改动，**保存**才写进 `%LOCALAPPDATA%\RenPyDocs\settings.txt` 并生效
- 文档页里注入的悬浮按钮、切换文档面板、搜索页 / 收藏页 / 选择页的正文文案、底部免责声明都跟随界面语言（`build.py` 里的四语言 `UI_TEXT` 字典）；文档正文、左侧目录、搜索页的常见主题 chips 和搜索结果里的章节名保持原文
- 快捷键：`Alt+←` 或 `Backspace` 后退（输入框内不触发）；标签相关见上文“标签页”
- 所有页面底部有灰色小字免责声明（英文文档是英文版）

## 目录结构

```
app/
├─ RenPyDocs.exe             主程序（WebView2 外壳）
├─ Ren'Py 中文文档.lnk       快捷方式
├─ app.ico / *.dll           图标与 WebView2 运行时组件
├─ site/                     文档镜像（唯一数据源）
│  ├─ index.html             跳转到 zh-CN/index.html
│  ├─ version.txt            中文文档版本号（如 8.5.4）
│  ├─ docs.json              文档列表（id / 名字 / 首页 / 版本），桌面端启动时读它
│  ├─ zh-CN/                 中文文档（doc.renpy.cn）
│  │  ├─ index.html          文档首页
│  │  ├─ search.html         搜索页（由 index.html + 模板生成）
│  │  ├─ favorites.html      收藏页（同上，模板是 favorites_body.html）
│  │  ├─ search-index.js     搜索索引，约 1.6 MB
│  │  ├─ *_index.html        4 个 Sphinx 生成的索引页
│  │  ├─ genindex.html       术语总索引
│  │  ├─ _static/            主题 CSS / JS / 图标 / 字体
│  │  └─ *.html              文档页
│  └─ en/                    英文文档（www.renpy.org/doc/html，106 页，约 20 MB，首次使用时下载）
├─ src/                      程序源码
│  ├─ Program.cs             主窗口、页面交互、更新流程、文档切换
│  ├─ TabStrip.cs            顶部标签栏（自绘控件，与页面无关）
│  └─ Updater.cs             应用内更新
├─ updater/                  构建载荷
│  ├─ build.py               页面改写 + 索引 + 搜索页/收藏页/选择页生成
│  ├─ fetch_en.py            文档抓取（六份共用，按 `base` 抓不同站点）
│  ├─ download_doc.py        单份文档的下载 + 重建（独立进程）
│  ├─ search_body.html       搜索页模板
│  ├─ favorites_body.html    收藏页模板
│  └─ python/                内嵌 Python 3.12
└─ tools/                    打包脚本
   ├─ build.ps1              一键重建（页面 → exe → 快捷方式）
   └─ ui_block.html          注入每个页面的 UI 代码块（`build.py` 里 `FAB` 的副本）
```

镜像规模：中文 114 个 HTML（112 个文档页 + 生成出来的搜索页/收藏页/选择页）、94 个静态资源，约 25 MB；
繁中 / 英文 / 日文 / 英文每夜版 / 英文每夜预发布版这五份**默认都不带**，点了下载才各自落到 `site\<id>`，每份 20～45 MB（日文那份实测 108 个页面、8.6.0）。
发布包整个 `app` 目录约 54 MB。
检索索引：中文覆盖 104 篇正文的 1239 个章节、约 86.7 万字；其它文档下载后各自生成一份。

## 重新打包

改完页面或源码后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File app\tools\build.ps1
```

它做三件事：

1. 用 `updater\build.py` 重写所有页面（注入 `FAB` 里的界面代码、重建索引，并生成搜索页和收藏页）
2. 用 `csc.exe` 编译 `src\Program.cs` + `src\TabStrip.cs` + `src\Updater.cs` → `RenPyDocs.exe`
3. 重建快捷方式（应用目录里一份、桌面一份、已固定到任务栏的话再修一次），并刷新图标缓存

> 编译前脚本会自动结束正在运行的 `RenPyDocs.exe`，否则 exe 被占用无法覆盖。

想调整界面（标签栏、顶部导航按钮、悬浮按钮、搜索记录、灯箱等），改 `updater\build.py`
里的 `FAB` 字符串即可，脚本会把它同步到全部页面；`tools\ui_block.html` 只是同一段代码的
副本，改完顺手同步一下即可。
